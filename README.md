Blender AI Addon

A powerful Blender addon powered by the Gemini API.

Installation Instructions

Open Blender.

Go to Edit > Preferences > Add-ons.

Click on the Install... button in the top right corner.

Select your downloaded addon file/archive and click Install Add-on.

Getting Started with the Gemini API

To use this addon, you need a Gemini API key (free or paid options are available):

Go to Google AI Studio https://aistudio.google.com/?utm_source=gemini to create your free Gemini API account.

Generate your API Key from the dashboard.

Open the addon settings inside Blender Edit Preferences and paste your API key into the designated field to get started!
